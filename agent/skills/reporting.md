# Skill: Reporting & Communication

Áp dụng khi cần viết báo cáo trạng thái, digest standup, release note, hoặc cập nhật stakeholder.

## Khi nào kích hoạt
Từ khóa: "báo cáo", "report", "tổng hợp", "cập nhật cho sếp", "release note", "tuần này", "weekly", "status".
Hoặc theo lịch: standup digest mỗi sáng, weekly report mỗi thứ Sáu.

## Các loại báo cáo

### a) Daily standup digest (gửi sáng)
Tổng hợp từ skill sprint_tracking: hôm qua done / hôm nay làm / blocker. Ngắn, nhóm theo người.

### b) Weekly status report (gửi cuối tuần)
```
📈 Weekly Report — Tuần 24 (10/06–16/06)

Sprint 12: 64% (14/22 task)
Velocity: 18 điểm (tuần trước 15) ↗️

Đã xong tuần này:
- Combat hitbox system ✅
- Enemy AI patrol v1 ✅

Đang làm: combat VFX, boss balance

🔴 Blocker: 1 (VFX combo chờ Art)
⚠️ Rủi ro: Alpha có thể trễ ~5 ngày nếu không cắt scope

Milestone Alpha (30/06): 72%, còn 20 ngày
```

### c) Release note (khi đóng build/version)
Nhóm thay đổi theo: Features mới · Cải thiện · Bug fixes · Known issues. Lấy từ task Done có tag release.

### d) Stakeholder update (gọn cho lãnh đạo)
3 dòng: tình hình chung (xanh/vàng/đỏ) · điều cần biết · điều cần hỗ trợ. Tránh chi tiết kỹ thuật.

## Quy trình
1. Xác định loại báo cáo + khoảng thời gian.
2. Kéo dữ liệu từ Notion (Tasks/Sprints/Milestones/Risks) trong khoảng đó.
3. Tổng hợp đúng template, chỉ dùng số liệu thật.
4. Gửi vào nhóm Zalo; nếu báo cáo dài, ưu tiên bản tóm tắt + đề nghị xem chi tiết trên Notion.

## Nguyên tắc
- Trung thực: báo cáo cả tin xấu (trễ, blocker), không tô hồng.
- Mỗi báo cáo kết bằng "điều cần PM/team quyết hoặc hỗ trợ".
- Không spam: đúng lịch hoặc khi được yêu cầu.
